# できたよ チャレンジ（MieeL）

特別支援学校向けの「できた！」を ほめて ふやす iPad アプリです。食べることに しぼった「もぐもぐチャレンジ」の しくみを、毎日の行動（したく・もちもの・せいけつ・うんどう・ことば・きりかえ など）に広げました。

## できること
- **3つの すすめかた**
  - 🔢 じゅんばん … あさの したく・トイレ・きゅうしょく など、手順を1つずつ（見とおしカード→1つずつ「できた！」）
  - 🎒 もちもの … リュックに「いれる／だす／もった？」を すきな じゅんに タップ（カードが リュックへ とんでいく）
  - 🔁 かいすう … あるく 5しゅう、なわとび 10かい など
- **できること 約360こ**（20の なかま：したく・せいかつ に くわえて、べんきょう・おんがく・ずこう・たいいく・さぎょう学習・ちょうり・じりつ活動・あそび・ぎょうじ／校外学習 など）＋ 先生が ことば・えもじ・実物の写真で 自由に つくれる
- **ひな形 30こ**（したく・せいかつ／がっこうの かつどう／からだ・きもち・ことば の 3グループ。さぎょう学習、ふくろづめ、のうえんげい、ちょうり、おんがく、ずこう、たいいく、ひなん訓練、かいもの学習 など）
- 子どもごとの チャレンジ・ごほうび（えらぶ／きめる／シールだけ）・シールちょう（40しゅるい）
- じかんの めやす（あかい えんばん。すぎても しっぱいに しない）、ながおしで「できた」
- **きろく**：クリアした日・時刻・かかった時間。CSV（Excel）で かきだし → 個別の指導計画の評価に
- バックアップ（べつの iPad へ）、とちゅうから つづき、画面スリープ防止、読み上げ・効果音

## つかいかた
- 右上の ⚙️ を **1.5秒 ながおし**（または Shift + S）で 先生用せってい
- iPad では「共有 → ホーム画面に追加」で アプリのように つかえます
- データは その端末の中だけに 保存されます（サーバーには 送りません）
